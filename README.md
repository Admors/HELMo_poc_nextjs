# ImmoVision — Proof of Concept

## Description

Ce projet est un **Proof of Concept (POC)** visant à évaluer si la technologie **Next.js** est adaptée au développement du projet scolaire **ImmoVision**.

L'objectif de ce POC est d'explorer les principales fonctionnalités nécessaires au projet et de vérifier que Next.js permet de répondre aux besoins techniques et fonctionnels identifiés.

Ce projet ne constitue pas l'application finale **ImmoVision**. Il sert uniquement à valider les choix technologiques avant le développement du projet.

## Objectifs

Ce POC a pour objectifs de :

* Découvrir et évaluer **Next.js**.
* Vérifier son adéquation avec les besoins d'ImmoVision.
* Tester la création de pages et de composants.
* Évaluer la gestion du routage.
* Tester la récupération et l'affichage de données.
* Évaluer l'intégration avec une API ou un backend.
* Observer l'expérience de développement avec Next.js.
* Identifier les éventuelles limitations ou difficultés rencontrées.

## Technologies

* **Next.js**
* **React**
* **TypeScript**
* **Node.js**
* **npm**

## Prérequis

Pour utiliser ce projet, vous devez disposer de :

* [Node.js](https://nodejs.org/) installé sur votre machine.
* `npm` installé avec Node.js.
* Un éditeur de code tel que **Visual Studio Code**, **Rider** ou autre IDE compatible.

Il est également recommandé d'avoir **Git** installé afin de récupérer le projet.

## Installation

Clonez le dépôt :

```bash
git clone <URL_DU_REPOSITORY>
```

Accédez au répertoire du projet :

```bash
cd <NOM_DU_REPERTOIRE>
```

Installez les dépendances :

```bash
npm install
```

## Lancement

Pour lancer l'application en mode développement :

```bash
npm run dev
```

L'application sera ensuite accessible à l'adresse :

```text
http://localhost:3000
```

## Tests du POC

Le POC permet notamment de tester les éléments suivants :

### Interface utilisateur

Vérification de la facilité de création d'interfaces avec React et Next.js.

### Routage

Vérification de la gestion des différentes pages et routes nécessaires à ImmoVision.

### Récupération des données

Test de la récupération de données depuis une source externe, telle qu'une API.

### Gestion des composants

Évaluation de la possibilité de créer des composants réutilisables afin de structurer l'application.

### Backend et API

Évaluation des possibilités offertes par Next.js pour communiquer avec un backend et/ou exposer des endpoints API.


## Conclusion

Ce POC permettra de déterminer si **Next.js** répond suffisamment aux besoins techniques du projet scolaire **ImmoVision**.

Les résultats et observations obtenus au cours des différentes expérimentations serviront à déterminer si cette technologie peut être retenue pour le développement du projet final.
